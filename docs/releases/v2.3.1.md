# Network Drives 2.3.1

- Show a persistent summary when a group connects incompletely, with each unresolved drive and its saved server.
- Find a missing SMB share across discovered LAN servers using existing macOS sessions.
- Review matching locations and explicitly update a saved drive while retaining its group memberships and previous address.
- Keep ambiguous matches visible; never infer physical disk identity from a share name or send stored passwords to other servers.

Search requires accessible SMB shares. Offline disks, renamed shares, undiscoverable servers, and servers requiring sign-in may not appear. Finder requests still awaiting sign-in are reported as unresolved, not confirmed hardware failures.

Validation: Python service regression tests and Swift compilation; packaged builds verified on Apple Silicon and Intel by CI. No real drives were moved or disconnected during testing.
