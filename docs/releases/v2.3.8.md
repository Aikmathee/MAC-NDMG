# MacNDMG 2.3.8

Add update reminders linked to the project's GitHub Releases installers. The app checks once per 24 hours by default while open; Updates offers every 48 hours, Off, and Check now. Preferences and reminder times survive app restarts. A quiet in-app banner links to the exact release page, where users download and install manually. No automatic installer download or installation is performed.

Only a newer stable published version with complete Apple Silicon and Intel installers qualifies. Drafts, prereleases, incomplete uploads, equal/older versions, and arbitrary release URLs are ignored. Offline or rate-limited checks stay quiet and do not repeatedly retry. Manual checks bypass the schedule.

The update request goes to the public GitHub API without login, saved drive/account details or cookies. It does not use macOS notification permission or run while the app is closed.

Validation: 96 Python regressions, native service tests, and native update tests for numerical version comparison, release readiness, 24/48-hour cadence, restart persistence, Off/manual modes, offline checks and already-current installs. Both architectures compile and run checks in CI.
