# MacNDMG 2.3.5

Fix shared action-button hit regions throughout Overview, Connected, Groups, server details, connection dialogs, recovery dialogs, Help and Activity. The shared styles now render a single padded button label with an explicit capsule hit region matching its visible bezel, rather than nesting a system Button inside a primitive button style.

Buttons have a minimum 36-point height, visible rounded borders, full-area hover feedback, native interactive Liquid Glass on macOS 26, disabled feedback, and native materials on earlier macOS versions. Keyboard activation, default/cancel shortcuts, roles and accessibility remain managed by SwiftUI Button. Menu glyphs have explicit 32-point target areas.

Validation: Python service regressions, Swift compatibility and SDK 26 compilation, plus edge-click checks across pages and sheets. No real drives are ejected during UI validation.
