# MacNDMG Preview 1

Start the public preview series at **Preview 1**. The app and release title show this name; internal version 2.3.9 preserves correct ordering for update checks. Preview 2 and later will retain increasing internal versions.

Add a compact **About & support** menu with About MacNDMG, Updates, Contact me (Instagram), Report a bug (GitHub Issues) and Buy me a coffee. These open their websites; the app does not send a report or make a payment. The bug report template includes app/build details and a reminder to remove private data before posting.

Includes update reminders: check every day or every 2 days, turn automatic checks off, or Check now. New complete published releases show an in-app banner linking to their installer page. Users download and install manually.
