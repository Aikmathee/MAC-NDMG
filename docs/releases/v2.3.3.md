# Network Drives 2.3.3

Discover SMB server names through macOS NetBIOS as well as Bonjour and DNS. Servers visible in Finder through NetBIOS previously appeared as generic IP-only hosts or disappeared after disconnecting.

Short SMB names are resolved against the current network. A discovered server name is used as a connection destination only when its current resolved address matches the probed server. Failed or blocked NetBIOS requests retain the numeric discovery result. Remembered SMB servers remain visible independently of discovery.

Validation: 85 Python regression tests and a read-only LAN discovery check. No drives were connected or ejected during validation. Apple Silicon and Intel packages are built and verified in CI.
