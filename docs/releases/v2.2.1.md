Includes the Liquid Glass interface from v2.2.0, with a window restoration refinement: the app uses the frame already saved by macOS before applying the initial window size.

ใช้ขนาดหน้าต่างที่ macOS บันทึกไว้ก่อนค่าตั้งต้น พร้อมการปรับ Liquid Glass ทั้งหมดจาก v2.2.0

Network Drives now uses native Liquid Glass controls and navigation on macOS 26.

## What's new

- A resizable sidebar, native window toolbar, and remembered window size.
- System glass button styles and a single glass surface for batch actions.
- Overview puts connected drives and compact saved groups first.
- Calmer, readable drive rows, larger Open/Eject click targets and rounded selection.
- Native grouped Add server and sign-in forms, with existing Keychain behavior preserved.
- Materials and animation respond to transparency, contrast and motion accessibility preferences.

เวอร์ชันนี้ปรับตามแผน Liquid Glass: แถบนำทางและชุดคำสั่งใช้วัสดุของระบบ ข้อมูลอ่านง่ายขึ้น หน้าแรกเน้นไดรฟ์และกลุ่มที่ใช้งาน และหน้าต่างจำขนาดได้

Download the Apple Silicon DMG for M1 or newer, or Intel DMG for Intel Macs. Open it and drag the app to Applications. Python is included. Requires macOS 13+; Liquid Glass controls require macOS 26. Earlier systems use compatible standard controls/materials.

Both downloads are built with Xcode 26 / SDK 26+. This app is ad-hoc signed and not Apple-notarized. For first launch, follow [Apple's instructions](https://support.apple.com/en-au/102445) if blocked. FTP/SFTP mounting is not included. Private remote servers require the appropriate VPN access.
