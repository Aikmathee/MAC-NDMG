## Included

- Native SwiftUI interface with System, Light and Dark modes; Liquid Glass on macOS 26.
- Live connected-drive inventory, Open, Eject selected and Eject all.
- Command-click / Shift-click selection and context menus for bulk actions.
- Saved drives and manually connected groups across multiple servers.
- SMB sign-in sheets with optional macOS Keychain storage.
- Direct SMB destinations through Tailscale/VPN/DNS and WebDAV endpoints.

## First launch

This version is **ad-hoc signed, not Apple-notarized**. macOS may block first launch. After verifying the source, follow [Apple's instructions](https://support.apple.com/en-au/102445) using System Settings → Privacy & Security → Open Anyway for this app. Do not disable Gatekeeper.

FTP/SFTP mounting is not included. Remote connections require a reachable server and, for private SMB, an active VPN. Authenticated remote mounts still need validation against your own server. SHA256SUMS.txt lets you verify download integrity.
