# MacNDMG 2.3.6

Complete the app-wide button hit-region fix from 2.3.5. Apply native Liquid Glass to the padded button label itself, preserving readable text when several buttons share a glass container.

All shared command buttons have explicit rounded hit regions matching their visible bezels, minimum 36-point height and hover borders. Keyboard shortcuts, accessibility and disabled states remain supported.

Validation: 85 Python regression tests; Swift compatibility and SDK 26 builds; real edge-click checks of View all, Select all, Deselect all, dialog Done/Cancel, group disclosure and server menus. No user drives were ejected.
