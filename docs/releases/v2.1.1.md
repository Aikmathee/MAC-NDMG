A small visual update for a more consistent Mac interface.

- Rounded selection highlights in Groups, Connected and shared drives, preserving native Command/Shift selection and context menus.
- Plain group headings and a rounded empty-state card instead of rectangular section bars.
- Removed the obsolete website prototype, legacy UI and sample network configuration from the source project.

Download the Apple Silicon DMG for M1 or newer, or the Intel DMG for an Intel Mac. Open it and drag the app to Applications. Requires macOS 13+. Python is included.

เลือกไฟล์ DMG ตามชิปของ Mac เปิดแล้วลากแอพไปยัง Applications เวอร์ชันนี้ปรับมุมโค้งของรายการที่เลือกและช่อง Groups

This build is ad-hoc signed and not Apple-notarized. On first launch, follow [Apple's instructions](https://support.apple.com/en-au/102445) if macOS blocks it. FTP/SFTP mounting is not included. Remote servers require the appropriate VPN/network access.
