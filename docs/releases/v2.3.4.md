# MacNDMG 2.3.4

Restore the app's name to MacNDMG in the sidebar, menu bar, window, app bundle, disk image and installation instructions. The bundle identifier, saved groups and Keychain namespace remain unchanged. Existing download URLs remain compatible.

Overview, Connected and Groups now accept clicks throughout their rounded navigation rows, including empty space. Hovering highlights the full row using interactive Liquid Glass on macOS 26; older systems use a native material. Command buttons use the system glass style on macOS 26, and the group disclosure has a visible button bezel. Disabled controls and Reduce Motion remain respected.

Validation: 85 Python service tests, Swift compatibility compilation, SDK 26 package compilation and visual checks of navigation clicks away from the text.
