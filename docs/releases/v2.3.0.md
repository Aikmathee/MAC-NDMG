# Network Drives 2.3.0

- Include SMB servers already connected by Finder, even when short Bonjour scans or the primary subnet miss them. Resolve Bonjour services concurrently with a longer response window.
- Confirm bulk ejects and keep normal macOS unmounting. Failed ejects show a dedicated sheet with the cause, detected apps/PIDs, Details, Retry and Activity Monitor. No force eject or automatic app termination.
- Try existing macOS SMB sessions before asking for credentials. Use Finder offers the system sign-in flow; no Finder password is extracted or copied.
- Shorten page titles and empty states. Move selection shortcuts, VPN/address explanations and account guidance into Help and contextual address help.

Validation: 70 service tests cover discovery fallback, alias deduplication, session reuse URLs, bounded process diagnostics, busy drives, timeouts and stale mount identities. A read-only check on an already connected SMB server listed shares through the existing Finder session without entering credentials. Actual user drives were not ejected during testing. Process visibility remains limited by macOS permissions.

Download the DMG for Apple Silicon or Intel below, then drag Network Drives into Applications.

UI verification used a private fixture that intercepted every eject request without calling unmount. The failure sheet, Details, Retry, and canceling bulk eject were checked with all 35 live drives remaining mounted. The fixture is not included in distributed packages.
