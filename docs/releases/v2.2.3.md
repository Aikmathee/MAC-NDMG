# Network Drives 2.2.3

- Prefer discovered Bonjour/DNS hostnames over numeric IPs for SMB connections and saved servers.
- Keep hostname-based destinations and group members stable when DHCP changes a server's IP.
- Match numeric mounted endpoints against the hostname's current resolution without saving IP aliases as destinations.
- Prefer a known hostname when saving a group from connected drives; retain existing groups and explicit IP entries.

Connections already mounted by IP keep that endpoint until reconnected by hostname. Old IP-only saved servers and groups need a one-time update to their hostname-based destination; the app does not guess which machine an old IP belongs to.

Validation: 52 service tests, including simulated DHCP changes, hostname reconnect URLs, numeric mount matching, and preservation of old group membership. Real LAN discovery verified hostname-first destinations without mounting or ejecting user drives.
