# Network Drives 2.3.2

Saved SMB servers remain in Servers even when Bonjour does not advertise them and no drive is currently mounted. Previously these destinations existed in saved drives but disappeared from the sidebar after disconnecting or refreshing.

Live connections and discovery still update the list. A saved entry does not imply the server is online. No stale IP addresses are inferred from history.

Validation: 80 Python regression tests, Swift compilation, and packaged builds for Apple Silicon and Intel.
