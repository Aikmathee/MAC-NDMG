# Changelog

## 2.1.0

- Native SwiftUI Mac interface with Liquid Glass, light and dark appearance.
- Live network drive inventory and safe bulk eject.
- Native multi-selection for servers, drives and groups.
- Saved drive groups and optional SMB accounts in macOS Keychain.
- SMB URL and WebDAV destinations for VPN, Tailscale and DNS access.
- Ready-to-install Apple Silicon and Intel release packages, clear download buttons and Thai installation guide.
- Build scripts and documentation separated from the app and informational website.
