# Changelog

## 2.2.1

- Preserve the window frame already saved by macOS when initializing the new window restoration policy.

## 2.2.0

- Native resizable split navigation and a system Liquid Glass toolbar on macOS 26.
- System glass buttons and a shared glass surface for selection actions.
- A practical Overview showing connected drives and compact saved groups first.
- Standard content surfaces, larger row action targets and native grouped sign-in/add forms.
- App window size restoration, semantic colors and accessibility-aware materials/animation.
- Separate design and page files; SDK 26 is required and verified for both release architectures.

## 2.1.1

- Rounded native selection highlights in Groups, Connected and shared-drive lists.
- Clean group headings and a rounded empty-state card.
- Removed obsolete prototype website, legacy UI and sample server configuration.

## 2.1.0

- Native SwiftUI Mac interface with Liquid Glass, light and dark appearance.
- Live network drive inventory and safe bulk eject.
- Native multi-selection for servers, drives and groups.
- Saved drive groups and optional SMB accounts in macOS Keychain.
- SMB URL and WebDAV destinations for VPN, Tailscale and DNS access.
- Ready-to-install Apple Silicon and Intel release packages, clear download buttons and Thai installation guide.
- Build scripts and documentation separated from the app and informational website.
